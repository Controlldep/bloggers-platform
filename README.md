Blogger Platform API
Этот проект представляет собой API для управления видеоплатформой, реализованный с использованием Express.js. Включает в себя различные модули для работы с авторизацией, видео, постами, комментариями и лайками.

Структура проекта
Проект разделён на несколько ключевых функциональных блоков, каждый из которых реализует свою функциональность:
authorization — авторизация пользователей, работа с токенами , проверка доступа и отправка писем на почту с кодом подверждения
blogs — управление блогами (создание, обновление, удаление)
comments — работа с комментариями (создание, обновление, удаление)
commentsLike — работа с лайками для комментариев
posts — работа с постами (создание, обновление, удаление)
postsLike — работа с лайками для постов
securityDevices — управление устройствами безопасности для аутентификации
users — работа с пользователями, регистрация и аутентификация

Описание
API включает в себя следующие основные возможности:
Авторизация: регистрация, вход, обработка JWT-токенов , отправка письма по почте для подверждения аккаунта , огранчиения на кол-во запросов на определнные эндпоинты с помощью express-rate-limit.
Управление пользователями: создание пользователей, обновление их данных, а также проверка аутентификации и авторизации.
Блоги: создание, обновление и удаление блогов.
Посты: работа с постами, включая создание, обновление и удаление.
Комментарии: создание, обновление и удаление комментариев.
Лайки: работа с лайками для постов и комментариев.

Стек технологий
Express.js — веб-фреймворк для Node.js
TypeScript — для статической типизации
MongoDB (Mongoose) — для хранения данных
JWT — для аутентификации и авторизации
Jest — для тестирования
express-rate-limit - для ограничения запросов на эндпоинты
